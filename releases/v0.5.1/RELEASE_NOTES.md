`late-attrition` 由评估工具定期模拟已造部队的战损；模组不会据此删除玩家或 AI 部队。其他场景没有这种测试战损。

Java 17 启动脚本调用已有 Java 17 和游戏 JAR，不替换原启动器。旧 Java 16.0.1 开发长测曾出现 C2 编译线程本机崩溃；本包记录 Java 17 对照测试的实际运行版本，不声称修复了 JVM。
